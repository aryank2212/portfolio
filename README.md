# Aryan Kumar - Portfolio

A stunning, Neo-Minimalist portfolio website featuring a Bento-Box layout, dark mode aesthetic, magnetic hover physics, and interactive tools. Built to showcase a dual expertise in Software Engineering and Cinematic Visual Effects.

🔗 **Live:** [Insert your live link here (e.g. Vercel / GitHub Pages)]

## 🚀 Features

### 🎯 High-Impact Design
- **Neo-Minimalist Aesthetic:** Deep true-black background (`#030303`) with ultra-high contrast pure white typography.
- **Bento-Box Grid:** Clean, asymmetrical cards for the "About" and "Skills" sections.
- **Edge-to-Edge Typography:** Massive, bold headings built with modern font stacks (`Inter` & `JetBrains Mono`).

### ✨ Interactive Elements
- **Magnetic Hover Physics:** Custom JavaScript logic applies a fluid magnetic spring-pull effect to navigation links, project cards, and social icons.
- **Scroll Reveals:** Buttery-smooth fade-up animations powered by `IntersectionObserver`.

### 🗂️ Project & Tool Showcases
- **Filterable Gallery:** Sort projects instantly between "All", "Engineering", and "VFX".
- **Interactive Tools:** Live-launchable physics simulations (Double Pendulum, N-Body Gravity), all accessible directly from the portfolio.

## 🛠️ Technologies Used
- Vanilla HTML5 / CSS3 / JavaScript (ES6+)
- DOM manipulation and Intersection APIs
- CSS Flexbox & CSS Grid (for Bento layout)
- Google Fonts (`Inter`, `JetBrains Mono`)
- FontAwesome Icons

## 💻 Running Locally

No build step or server is required. Simply open `index.html` in your favorite modern browser:

```bash
# Clone the repository
git clone https://github.com/aryank2212/portfolio.git

# Navigate to the directory
cd portfolio

# Open the file
open index.html
```
